# T5 · search_episodes 检索工具与提示词更新

依赖：T4 ｜ 预估：2–3 天 ｜ 风险：高（改动提示词，影响成功率）

## 目标

给规划器新增语义检索工具 `search_episodes`，并把 LIBERO 提示词的
"READ MEMORY" 段升级为三段式召回。提示词改动单独一个 commit。

## 先读

- `docs/memory-redesign.md` 第 2.5、3 节
- `rpent/tools/base.py`（@tool 约定、readonly 语义）
- `rpent/tools/toolkit.py`（add_tool / 调度）
- `robots/libero/tools.py`（现有观测类工具的 ToolResult 组装方式）
- `robots/libero/prompts/evaluate.py`（"READ MEMORY" 段）

## 要求

1. 新工具实现放 `rpent/episode/search_tool.py`，在 robot toolkit 构建处
   注册（仅当 episode 索引存在时注册，否则不暴露该工具）；
2. 工具行为严格按设计文档 2.5：robot 过滤恒等于当前机器人；
   `query_text`/`current_frame` 至少给一个，否则抛 `ValueError`；
3. ToolResult 中只返回摘要字段 + URI + memory_ids，**不回传图像字节**；
4. embedding/Milvus 任一不可用时：工具返回结构化错误
   `{"error": "episode_search_unavailable", ...}`，不抛异常给模型；
5. 提示词更新（**单独 commit**，message: `prompts: three-stage memory
   recall with search_episodes`）：
   - 保留原"读 MEMORY.md / 读正文裁决 / 登记已读文件"全部要求；
   - 在第①步索引导航与第③步读正文之间，插入第②步：
     调 `search_episodes(task_language, 当前首帧)` 召回相似历史情景；
   - grep 指引降级为"向量检索不可用时的备选"。

```bash
#   LIBERO 小子集（libero_object_task 前 3 任务 × 2 seed）成功率
#   不低于本分支基线
```

新增测试：参数校验、过滤逻辑、不可用降级、工具注册条件、
ToolResult 不含图像字节。

## 禁止

- 不改动其他提示词段落；
- 不在工具内部吞掉 Milvus 返回的元数据字段；
- 不把工具做成写操作（必须 readonly）。
