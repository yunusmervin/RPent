# T2 · Episode 数据模型与写入钩子

依赖：T1 ｜ 预估：2–3 天 ｜ 风险：中（触碰主流程收尾路径）

## 目标

定义 episode 数据模型，在任务收尾时把"这次执行发生了什么"落成
`episode.json` + 关键帧，写入 AGFS。本卡不做向量化。

## 先读

- `docs/memory-redesign.md` 第 2.2、3 节
- `rpent/cli/main.py`（收尾段：`merge_memory` 调用处与 stats 组装）
- `rpent/tools/toolkit.py`（`evaluation_metrics`、`write_recipe` 出口）
- `robots/libero/tools.py` 的帧录制（`record_frame` / `recorded_frame_count`）

## 要求

1. 新建 `rpent/episode/`：`model.py`（pydantic 模型，schema 见设计文档
   2.2，字段校验齐全）、`writer.py`（写 AGFS）、`hook.py`（收尾钩子）；
2. 关键帧抽取规则：
   - 首帧：episode 第一帧 agentview；
   - 成功帧：`terminated` 时的最后一帧；
   - 失败帧：`truncated`/人工 failure 时的最后一帧；
   - overlay：最近一次 `segment` 工具产出的 overlay（若存在）；
3. 钩子挂在 `merge_memory()` 成功返回之后；**仅当**（探索模式 或
   `args.explore`）或显式 `--record-episodes` 时启用；评测模式默认关闭；
4. 钩子全部异常必须 catch 并降级为 warning 日志，主任务退出码不受影响；
5. `memory_version`、`embedding_model` 字段先写入占位（T3/T4 填真值），
   字段本身本卡必须存在；
6. CLI 新增：`--record-episodes`（默认关）、`--episode-store-endpoint`
   （预留，本卡可只解析不生效）。

## 验收

```bash
pytest tests/unit_tests/ -q
pytest tests/unit_tests/episode/ -q
# 手工验证（附输出）：

#   agfs-shell ls /frames/sha256/                          # 帧已内容寻址落盘
#   重复跑一次，帧 uri 不变（内容寻址去重）
```

新增测试：模型校验（缺字段/非法 outcome 报错）、钩子幂等、异常降级
（mock AGFS 抛错时主流程正常返回）。

## 禁止

- 不改动 `merge_memory` 本体；
- 不在评测默认路径写入任何内容；
- 不在 episode.json 内联图像字节。
