# T6 · mem0 会话与偏好平面

依赖：T0（接口纪律）；与 T2–T5 可并行 ｜ 预估：2 天 ｜ 风险：低

## 目标

用 mem0 开源 SDK 管理会话历史与操作者偏好：写入交互内容，
规划时召回偏好注入 prompt。与任务记忆物理隔离。

## 先读

- `docs/memory-redesign.md` 第 2.6、3 节
- `rpent/cli/tui.py`（用户输入路径）
- `rpent/tools/human_in_the_loop.py`（人工 verdict 路径）
- `rpent/cli/main.py`（`build_planner` 调用处与 prompt_vars 组装）
- mem0 文档（开源 SDK 的 Milvus 后端配置）

## 要求

1. 新建 `rpent/session_memory/`：`service.py`（mem0 封装，
   向量后端 Milvus，collection `session_mem__prod`）、
   `hook.py`（写入钩子）、`recall.py`（召回）；
2. 作用域：`user_id=args.operator_id`（新增 CLI 参数，缺省
   `default_operator`），`run_id=cell_tag`；
3. 写入点（仅探索/交互模式，评测模式禁写）：
   - 任务指令首次提交；TUI 每行用户输入；人工 verdict；
4. 读取点：`build_planner` 之后用任务语言 `search` 召回 top5，
   渲染进 `prompt_vars["operator_preferences"]`；prompt 模板引用该变量
   （模板改动单独 commit）；变量为空时模板不得出现空段落；
5. mem0 初始化失败：降级为无偏好注入 + warning，主流程不受影响；
6. 评测模式：`--memory-profile hf` 下本平面只读。

```bash
#   --memory-profile hf 运行时 mem0 无任何写调用（mock 断言）
```

新增测试：评测禁写、降级路径、偏好注入渲染（含空值）、作用域隔离
（不同 user_id 互相不可见）。

## 禁止

- 不把 mem0 用于任务知识（那是平面 K/E 的事）；
- 不使用 mem0 托管云服务；不引入其图记忆依赖；
- 不在 transcript 中重复记录 mem0 内容（避免双写）。
