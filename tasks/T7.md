# T7 · 版本冻结与回归验证

依赖：T4、T5（T6 建议完成）｜ 预估：2 天 ｜ 风险：低

## 目标

提供一键冻结脚本，把"语料 + Milvus collection + AGFS 挂载"锁成
不可变的评测快照；并建立双跑一致性回归。

## 先读

- `docs/memory-redesign.md` 第 2.7 节
- `rpent/memory/source.py`（HF revision 解析）
- T4 的 collection 命名与 properties
- `tools/`（若无则新建）

## 要求

1. 新建 `tools/freeze_memory_version.py --robot <name> --version <v>`：
   - 语料：记录 HF revision 或本地 git commit；
   - Milvus：校验 `episodes__<v>` 存在，把冻结事实写入其 properties
     （`frozen=true, frozen_at=...`），后续 upsert 到已冻结 collection
     必须被拒绝（写路径检查 properties）；
   - AGFS：`/episodes/<v>/` 切只读（backend 配置层面实现）；
   - 生成 manifest（schema 见设计文档 2.7），落
     `memory/<robot>/_internal/freeze/<version>.manifest.json`；
2. 新建 `tools/check_freeze.py --robot <name> --version <v>`：
   校验 manifest 与三件套实际状态一致，退出码反映结果；
3. 双跑回归：文档化命令 + 脚本 `tools/replay_consistency.sh`——
   同一 suite/task/seed 用冻结语料连跑两次，transcript 剔除时间戳后
   diff 必须为空；不一致时输出首个分歧位置；
4. T4 的写路径补一个保护：向 frozen collection 写入抛 `RuntimeError`。

## 验收

