# T3 · Embedding 服务

依赖：T2（可并行开发，联调在 T4）｜ 预估：2 天 ｜ 风险：中（模型接入）

## 目标

提供独立进程的 `embedding_server`：文本与图像编码到同一向量空间，
模型锁定 Qwen3-VL-Embedding-2B；同时提供确定性 mock 供无卡环境。

## 先读

- `docs/memory-redesign.md` 第 2.3 节
- `rpent/robots/components/sam3_server.py`（服务进程骨架范本）
- `rpent/robots/components/pi05_vla_server.py`（模型加载与 RPC 暴露方式）
- `rpent/robots/runtime.py` 的 `try_spawn_server / try_wait_server`

## 要求

1. 新建 `rpent/robots/components/embedding_server.py` 与
   `embedding_client.py`，HTTP RPC 接口契约严格按设计文档 2.3；
2. 入参 `image_uris` 支持 `agfs://` 与 `file://` 两种 scheme；
3. `--mock` 模式：向量 = 对输入内容 SHA256 播种的 PRNG 生成，
   同输入恒得同向量；维度常量 `MOCK_DIM` 与真实模型维度一致，
   启动日志打印实际维度；
4. 模型版本字符串常量 `EMBEDDING_MODEL_ID = "Qwen3-VL-Embedding-2B@2026.10"`
   集中定义在 `rpent/utils/config.py`，T2 的占位字段改引用它；
5. 运行时接入：在 `robots/libero/robot_spec.py:_init_runtime` 的
   starters 里注册 `embedding` 组件，默认仅在 `--record-episodes` 或
   检索工具被启用时拉起；`--embedding-endpoint` 直连已有实例时不拉起；
6. 健康检查对齐现有组件（`try_wait_server`，超时 300s）。
